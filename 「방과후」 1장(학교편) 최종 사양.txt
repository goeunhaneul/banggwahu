1. 기본 설정
━━━━━━━━━━━━━━━━━━━━
- 제목: 「방과후」 1장 — 학교
- 주인공: 고등학생. 친구 지은, 태민, 하린과 야자가 끝난 뒤 학교에 남는다.
  · 태민: 허세 많고 겁 많은 분위기 메이커 / 지은: 분신사바를 제안한 장본인, 겁 많은데 인정 안 함 / 하린: 침착하고 팩트로 받아치는 친구
- 숨겨진 진실: 학교 지하에 가상의 종교 '무명회(無明會)'의 기도실이 있다. 담임 윤 선생님이 지도자이고 밤마다 의식을 올려 왔다. 아이들의 분신사바가 그 의식에 문을 열어준 셈이다. 곳곳에 쪽지를 남긴 '선배'는 10년 전 같은 일을 겪은 학생이다.
- 무명회는 가상의 종교. 목탁·염주·촛불·병풍·위패 분위기만 쓰고 실제 경전·종교 명칭은 쓰지 않는다.
- 분위기: 공포 중심. 개그는 안전한 순간(프롤로그, 이동 중, 세이브 포인트, 평범한 사물 조사)에만 한 문장으로. 귀신 등장·추격·친구 실종·기도실·엔딩은 진지하게.
- 목표: 학교 정문을 나가 탈출.

━━━━━━━━━━━━━━━━━━━━
- 논리 해상도 480×320, 타일 16px, 창 크기에 맞춰 정수 배율로 확대(픽셀이 뭉개지지 않게).
- 학교는 어둡고 주인공 주변만 손전등처럼 둥글게 보인다(손전등 얻기 전엔 작게). 운동장은 조금 밝게.

- 대화가 이어지는 장면에서는 오른쪽 위에 "건너뛰기 (Q)". Q를 누르면 대사·대기·연출은 넘기고 아이템·플래그·목표·맵 이동 같은 진행 정보는 그대로 적용. 선택지와 마지막 "타이틀로" 입력에서는 멈춘다.
- 비명은 소리와 함께 화면 가운데 크게 흔들리는 붉은 글자로 표시.
- 문 위에 이름표(가까이 가면 표시).

4. 맵 (오브젝트는 서로 겹치거나 통로를 막지 않게)
━━━━━━━━━━━━━━━━━━━━
- 2층 복도(가로로 긴 복도): 2-1반(들어갈 수 있음), 2-2반(잠김), 2-3반(우리 반), 과학실, 미술실, 음악실, 비상구(밖에서는 잠김), 오른쪽 끝 계단.
- 1층 복도: 1-1반, 화장실, 1-2반, 교무실, 오른쪽 끝 계단, 오른쪽 벽 끝 현관 문.
- 과학실 + 과학 준비실: 과학실 출입구는 오른쪽 아래, 준비실 문은 그 반대편인 왼쪽 위.
- 음악실: 원래 출구(왼쪽 아래)와 반대편 오른쪽 벽의 비상구(2층 복도 비상구 위치로 나온다).
- 교무실: 복도 쪽 문 + 안쪽 잠긴 문(지하 기도실로).
- 지하 기도실, 현관(신발장이 있는 별도 공간, 운동장 쪽 유리문에 자물쇠), 운동장, 정문.
- 들어갈 수 없는 문은 어디인지 말하지 않고 "문이 잠겨 있다."만 표시. 잠긴 문에 부딪히면 그 문 앞 바닥 칸으로 되돌린다(벽 안으로 밀려 들어가 갇히지 않게). 혹시 벽·물건 안에 끼면 가장 가까운 빈 바닥으로 자동으로 빼낸다.
- 계단: 2칸 폭. 밟는 순간 다른 층으로 이동하고, 도착은 계단 바로 옆 칸. 도착 후 방향키를 한 번 떼야 다시 움직이게 해서 누른 채로 되돌아가지 않게. 문을 지난 직후 잠깐(약 0.3초) 문 판정 무시.
- 층 이동 순서를 지키도록 문 조건: 과학실은 화장실을 끝낸 뒤, 음악실은 음악실 열쇠가 있어야, 미술실은 음악실을 끝낸 뒤, 교무실은 미술실을 끝낸 뒤 열린다.
- 교실(모든 반 같은 구조): 칠판(위쪽 벽), 교탁(숨을 수 있음), 창문, 책상, 사물함.
  · 캐비닛은 두지 않는다. 사물함은 교실 뒤쪽 벽(아래쪽 벽)에 한 줄로 붙여 문이 교실 안쪽(위)을 향하게. 우리 반 6개(손전등 사물함 포함), 다른 반 4~5개.
  · 교실 사물함은 전부 숨을 수 있다(아이템을 꺼낸 사물함 포함).
  · 사물함마다 명찰과 한 문장 대사가 다르다. 예: "'김태민' 사물함에서 축구화 냄새가 강렬하게 난다." / "'오민지' 사물함엔 우유가 치즈가 되어 있다."
  · 책상마다 서로 다른 한 문장 대사. 예: "서랍에 반쯤 먹은 초코파이가 있다." / "책상에 '수학 싫어'가 새겨져 있다." / "'이 자리 귀신 나옴 ㅋㅋ'이라는 낙서가 하나도 안 웃기다."
- 복도에는 캐비닛·청소도구함·학생회 물품함을 두지 않는다. 복도 사물함은 벽 안에 매립된 장식(숨기 불가, 몇 개만 한 문장 대사).
- 그 밖의 사물 조사는 대부분 대사 없이, 남기는 것은 한 문장 개그만. 예: 자판기 "500원이 없다는 현실이 귀신보다 차갑다.", 해골 "해골이다. 얘는 다행히 얌전하다.", 석고상 "얘도 움직이면 진짜 퇴학이다."

[1] 2학년 3반 교실: 분신사바
- 도착하면 불이 꺼져 있다. 하린 "봐, 꺼져 있잖아." → 형광등 하나를 켜고 둘러앉는다(책상 위 시점 장면, 넷이 책상 네 면).
- 안전한 개그 대사 몇 줄(태민 "귀신 나오면 내가 먼저 인사한다. 예의가 있지.", 하린 "너 저번에 노래방 화장실도 무섭다고 같이 가자 했잖아.", 지은 "나 안 무서워. 그냥 손이 좀 떨리는 거야. 추워서.").
- 종이에 검은 글씨로 O와 X → 넷이 "분신사바 분신사바, 오셨습니까?" → 정적 → 빨간 펜이 O에 천천히 동그라미(펜이 원을 따라 움직임).
- 무서워하는 대사 후 질문: 태민 "화장실 변기 귀신 진짜 있어?" / 지은 "과학실 인체 모형 밤에 움직인다는 거 진짜야?" / 하린 "음악실 피아노는?"
- 빨간 펜이 "전부 있어"를 한 글자씩 쓴다 → 형광등이 깜빡이다 꺼지고, 다시 켜지면 펜만 책상 위에 서 있다 → "……귀신이 진짜 풀려났을까?" (단정하지 않기)
- 교실로 이동하면서 수첩을 이미 갖고 있다("가방 속 수첩이 손에 잡혔다. Tab으로 열 수 있다."). 세이브 없이 죽으면 이 시점부터 다시 시작.
- 우리 반 사물함: 내 사물함에서 손전등, '정서연' 사물함 깊숙한 곳에서 부적("누가 이런 걸 학교에 두고 다니지…….").
- 칠판 옆 게시판이 첫 세이브 포인트. 바로 옆 바닥에 선배 쪽지.
- 교실 문은 손전등이 있어야 나갈 수 있다("너무 어둡다. 손전등부터 찾자.").

[2] 2층 복도 → 1층 화장실: 변기 귀신
- 복도로 나오면: 하린 "정문은 1층 현관 쪽이야. 계단부터 가자." / 지은 "난 가운데서 걸을게. 이유는 묻지 마." / 태민 "아 나 진짜 급해. 귀신보다 이게 더 무서워." → 태민이 혼자 1층 화장실로 걸어간다 → 정적 → scream_taemin.mp3와 동시에 화면 가운데 "아아악—" (소리가 실제로 재생되기 시작한 순간에 글자 표시).
- 1층 1-2반 '신유찬' 사물함에서 변기 뚫어뻥: "왜 교실에 이게 있지. 일단 챙긴다."
- 화장실 문 앞에서 지은·하린은 밖에서 기다린다(안에는 혼자).
- 화장실: 칸 5개가 위쪽에 나란히, 앞에 2줄 통로. 무작위 칸에서 물 내리는 소리(좌우 소리 위치로 어느 칸인지 들림). 그 칸은 칸 전체(변기 칸과 문)가 어둡게 보인다(바닥 웅덩이는 쓰지 않음). 그 칸 앞을 지나가면 검은 손이 나와 즉사. 플레이어가 서 있거나 바로 옆인 칸은 물이 내려가지 않게(불공정 방지).
- 입구 쪽 벽 낙서(MinjaeHand): "물 소리 나는 칸 앞으로 지나가지 마"
- 마지막 칸에서 태민의 휴대폰(메모는 컴퓨터 글씨체), 금고 숫자 ①, 젖은 쪽지 획득.
- 휴대폰을 찾으면 모든 칸에서 물이 내려가고, 화장실 전체가 점점 검게 물들며, 약 1.4초 뒤 마지막 칸에서 사람 모양의 검은 그림자가 일어나 쫓아온다(속도 1.34, 젖은 손자국을 남긴다). 휴대폰을 찾기 전에는 그림자가 나오지 않는다.

[3] 1층 복도: 젖은 태민
- 화장실을 나오면: 지은 "나왔다! ...태민이는?" / (휴대폰을 내민다) / 하린 "......태민이 거잖아." → 복도 저쪽에 태민이 서 있다 → 정적 → 지은 "엇, 저기 태민이 아니야?" / 하린 "다가가지 마. 잘 봐 봐, 전부 젖어 있어!" → 추격.
- 젖은 태민: 처음 5초 속도 0.5, 이후 화면 안에 보일 때 0.75 / 화면 밖일 때 0.5. 젖은 발자국을 남긴다. 어둠 속에서도 희미하게 보이게.

[4] 2층 과학실: 인체 모형 (지은과 함께, 하린은 복도에서 망)
- 인체 모형은 출구 옆에 서 있다. 지은 "...근데 출구 옆 저 인체 모형, 원래 저기 있었나?"
- 실험대 서랍을 처음 뒤지면 지은 실종 이벤트: 지은 "아 진짜 기분 나쁘게 생겼네. 뭘 봐!" → 모형에게 걸어가 "이 플라스틱 덩어리가 어디서 째려봐!" → 발로 찬다(효과음, 흔들림) → "흥. 봤지? 하나도 안 무서워." → 화면이 꺼지고 효과음과 함께 "꺄아악—" → 불이 켜지면 지은이 없다.
- 인체 모형: 주인공이 바라보는 방향(약 50도 부채꼴) 안에 있으면 멈추고, 등을 돌리면 다가온다(속도 0.72 + 0.04×진행 단계). 힌트는 대사 없이 젖은 쪽지로만.
- 실험대 서랍 중 하나에 준비실 열쇠. 준비실 책상에서 금고 숫자 ②, 음악실 열쇠, 지은의 쪽지(SujinHand) 획득.
- 준비실을 나올 때: 진열장 속 인체 모형 옆에 지은과 똑같은 얼굴의 모형이 서 있다(확대 장면).
- 과학실로 돌아오면 모형이 출구 근처에서 기다리며 추격 → 출구로 탈출.
- 과학실을 나오면 하린 "...지은이는? 같이 나온 거 아니었어?" → "......음악실로 가자. 이번엔 내가 같이 갈게."

[5] 2층 복도: 귀신이 된 지은
- 과학실을 마치고 복도에 나오면 정적 후 지은이 "나 여기 있어…"라고 부르며(말풍선 + 목소리) 다가온다. 닿으면 즉사. 하린 "......지은아?"
- 2-1반 '김민수' 사물함에서 리코더: "이름표에 '3반 김OO'. 빌려간다. 미안."

[6] 2층 음악실: 피아노 귀신 (하린과 함께)
- 들어가면 「엘리제를 위하여」가 흘러나온다. 하린 "......이 곡, 엘리제를 위하여잖아." / "근데 왜 이렇게 늘어지지. 아무도 없는데, 건반이 혼자 눌려."
- 악보함: 금고 숫자 ③ + 메모(SujinHand) "베토벤 선생님을 원래 자리로 돌려드려."
- 베토벤 초상화 옆 벽에 꽂힌 쪽지(SujinHand): "조심해. 옮길 때 이상한 존재가 우리를 따라와……"
- 초상화는 악보 메모를 읽은 뒤에만 뗄 수 있다. 떼는 순간 그림이 화면 가운데로 크게 확대되고, 눈동자가 두리번거리다 플레이어 쪽을 향해 멈추며 붉게 물든다. "(......그림 속 눈동자가 천천히 나를 따라 움직였다.)"
- 바로 귀신이 나오지 않고, 초상화를 뗀 자리에서 약 2걸음(28px) 움직이면 피아노가 뚝 멈추고 귀신이 바로 뒤에 선다.
- 피아노 귀신 규칙: 피아노 소리가 클수록 가깝다(화면 가장자리 ♪ 표시 + 왼쪽 아래 소리 막대). 소리가 멈추면 처음 1초는 반응 시간, 이어서 2초 동안 방향키를 누르면 즉사. 3초 뒤 귀신은 방 왼쪽으로 물러나 2초 쉬었다가 다시 다가온다(속도 0.9). 20px 안까지 붙으면 다시 멈춤 판정. 정지 판정 중에는 귀신 실루엣이 주인공 바로 뒤에 보인다.
- 초상화를 뗀 뒤 원래 출구는 잠기고 반대편 비상구로만 나갈 수 있다. 이 추격 중에는 "도망쳐!" 표시 없음.
- 비상구로 나오면: 하린 "......하아, 하아. 나왔어." / "원래 자리라니... 미술실에 빈 액자가 하나 있었던 것 같아."

[7] 2층 미술실
- 빈 액자에 초상화를 걸면 액자 뒤에서 현관 자물쇠 열쇠가 떨어진다. 하린 "......방금, 초상화가 웃은 것 같지 않았어?"

[8] 1층 교무실: 금고와 반전
- 윤 선생님 책상: "윤 선생님 책상 위에 염주와 낡은 경전이 놓여 있다." / "담임쌤 이런 거 하셨나."
- 바닥의 선배 쪽지(SujinHand): "밤에는 선생님한테도 들키지 마. - 선배가"
- 달력: 3일에 빨간 동그라미, "금고 ④" → 숫자 ④.
- 금고(4자리, 좌우로 자리·상하로 숫자): 비밀번호 4173 (①4 ②1 ③7 ④3).
- 금고 안에는 정문 열쇠가 아니라 기도실 열쇠와 윤 선생님의 수첩(NoticeHand): "오늘 밤도 문을 연다. 아이들이 스스로 불러주면 더 빨리 온다." → 하린 "……선생님이 이런 걸 했다고?" → 정적 → 펜 긁는 소리와 함께 분신사바 귀신(긴 머리, 교복, 검은 형체, 붉은 눈) 등장 → 약 1.3초 서 있다가 추격.

[9] 지하 기도실: 잠입
- 교무실 안쪽 잠긴 문을 기도실 열쇠로 연다. 하린 "난 여기서 망볼게. 무슨 소리 나면 바로 뛰어 와." (하린은 위에 남는다)
- 들어가면: "(촛불만 켜진 방. 병풍과 위패가 늘어서 있다.)" / "(가운데 제단 위에 열쇠가 놓여 있다. ...정문 열쇠다.)" / "(누군가 목탁을 두드리며 제단 주위를 천천히 돌고 있다.)" / "(......담임 윤 선생님이다.)"
- 방은 아주 어둡고 제단·벽의 촛불과 선생님이 든 촛불 주변만 밝다. 가운데 붉은 깔개, 제단, 네 구석 쪽에 병풍, 양쪽 벽과 아래쪽에 위패.
- 윤 선생님은 제단 주위 사각형 경로를 천천히 돈다(속도 0.45). 손에 든 촛불 빛 범위(부채꼴, 반지름 약 86px, 좌우 약 31도)가 바닥에 보이고, 그 안에 들어가거나 바로 옆(14px)까지 가면 발각 → 즉사. 병풍·위패·제단에 가려지면 보이지 않는다.
- 목탁 소리가 빨라지면 2초 뒤 선생님이 뒤를 돌아보고(약 2.5초) 다시 걷는다. 뒤돌아보는 간격은 약 8~12초. 경고 중엔 부채꼴이 붉은빛.
- BGM을 완전히 끄고 목탁 + 낮게 웅얼거리는 독경만. 화면 아래 가짜 경문이 천천히 흐른다: "밝음 없는 곳에 문이 열리나니" / "부르는 이 있으면 오는 이 있도다" / "어둠은 비지 않고 빈 것은 어둠이로다"
- 제단의 정문 열쇠를 집으면 촛불이 한꺼번에 꺼지고 독경이 멈춘다 → 1~2초 정적 → 윤 선생님 "……누가 왔니?" → 마지막 추격.
- 윤 선생님 추격: 가장 빠른 추격자(화면 안 1.15, 밖 0.85). 기도실 → 교무실 → 1층 복도 → 현관까지 따라온다. 현관 유리문으로 운동장에 나서는 순간 추격이 끝난다.

[10] 현관 → 운동장 → 정문
- 현관 유리문은 현관 자물쇠 열쇠로 연다(처음 한 번 "현관 자물쇠 열쇠로 자물쇠를 열었다.").
- 정문은 정문 열쇠로 연다. 열쇠 없이 조사하면 "정문이 쇠사슬과 자물쇠로 잠겨 있다." / "(...아까는 분명 열려 있었는데.)"

━━━━━━━━━━━━━━━━━━━━
6. 엔딩
━━━━━━━━━━━━━━━━━━━━
- 정문 앞에 도착하면 자동 이벤트: 정적 → "(열쇠를 꽂자 철컥, 자물쇠가 풀렸다.)" → 하린 "......먼저 나가. 나 교실에 펜 두고 왔어." / 나 "하린, 잠깐—" → 하린이 돌아보지 않고 학교로 걸어 들어간다 → 멀리서 목탁 소리가 다시 들린다.
- 선택지: 하린을 따라간다 / 정문을 나간다
  · 따라간다: 교실 책상에서 하린이 혼자 분신사바(종이에 "같이 하자")를 하고 있다 → "하린...? 펜 찾았으면 이제 가자." → 정적 → 돌아본 하린의 얼굴이 없다 → BAD END "그날 교실에서 나온 사람은 아무도 없었다." → 선택: 정문 앞에서 다시 하기 / 타이틀로
  · 나간다: 화면이 하얗게 → 「방과후」 1장 — 학교편 끝 → "다음 날 아침."
- 다음 날 아침(밝은 교실): "(교실 문을 열자, 지은, 태민, 하린이 평소처럼 앉아 있다.)" / 태민 "야 어제 너 왜 혼자 먼저 갔냐? 의리 없네." / 하린 "어제? 야자 끝나고 바로 집에 갔잖아. ……우리 넷이 같이." / "(지은은 말없이 웃고 있다. 평소처럼.)" / 윤 선생님이 교실에 들어와 "다들 어제 일찍 들어갔지?" / "(분명 어젯밤, 아무도 돌아오지 못했는데.)" / "(모두가 아무 일 없었다는 얼굴이다. ...나만 이상하다.)" → "2장에서 계속" → Space로 타이틀.
- 기도실에서 윤 선생님에게 잡히면(잠입 중이든 추격 시작 직후든 기도실 안이면) 전용 배드엔딩: 촛불이 다시 켜지면 제단 앞 흰 천 위에 주인공이 눈을 감은 채 눕혀져 있고 촛불 열 개가 둘러싸고 있다. 제단 뒤엔 얼굴에 그림자 진 윤 선생님, 목탁 소리만 이어진다. "(제단 앞에 새 제물이 놓였다.)" → BAD END "기도 시간에는 조용히." (피·잔인한 묘사 없이)

━━━━━━━━━━━━━━━━━━━━
7. 귀신 공통 규칙
━━━━━━━━━━━━━━━━━━━━
- 귀신은 무작위로 나오지 않는다. 특정 물건을 건드리거나 구역을 끝냈을 때만 이벤트로 등장(위 흐름 그대로).
- 귀신 등장 직전 1~2초 완전한 정적(BGM 파일도 멈춤). 개그 대사 직후라면 대사 → 정적 → 등장.
- 추격 중에는 조사·수첩(Tab)·세이브가 막히고, 문은 복도·계단·교실로 가는 문만 쓸 수 있다("지금은 들어갈 수 없다. 도망쳐야 한다!"). 윤 선생님 추격 때는 기도실·교무실·현관과 현관→운동장 문도 허용.
- 복도형 추격자(분신사바 귀신, 젖은 태민, 지은, 윤 선생님)는 층·교실을 따라온다: 문/계단을 지나면 거리에 따라 최대 2초 뒤 같은 문으로 들어오고, 따라오는 동안 발소리가 점점 커진다. 나타난 직후 약 0.7초는 보이는 채로 제자리에 서 있다. (따라온 귀신이 반드시 화면에 그려지게 할 것)
- 분신사바 귀신 속도: 화면 안 1.0 + 0.055×단계, 화면 밖 0.6 + 0.06×단계 (단계 = 끝낸 괴담 구역 수). 주인공 속도는 1.25(60fps 기준 px/프레임).
- 숨기: 교실 사물함과 교탁 아래에서만, 추격 중일 때만. 숨으면 시야가 사물함 틈새처럼 좁아지고 큰 카운트다운(4~6초)이 뜬다. 귀신은 숨은 곳 앞까지 와서 서성이며 문을 두드린다. 카운트다운이 끝나면 귀신이 떠나고 "Space: 나가기". 끝나기 전에 나오면 즉사.
- 따돌리기: 숨지 않아도 귀신 시야 밖에서 약 12초 동안 도망치면 "발소리가 멀어졌다. ...따돌린 것 같다."와 함께 사라진다(다른 층으로 이동 중일 때는 더 빨리 쌓인다).
- 귀신이 된 친구들은 어둠 속에서도 희미하게 보이게.

━━━━━━━━━━━━━━━━━━━━
8. 퇴치 아이템 (1회용, 해당 귀신에게 잡히는 순간 자동 사용)
━━━━━━━━━━━━━━━━━━━━
- 변기 뚫어뻥(1-2반 사물함): 화장실 칸의 검은 손 / 그림자 추격 1회. "뚫어뻥이 검은 손을 막아냈다! 뚫어뻥은 변기 속으로 사라졌다."
- 리코더(2-1반 사물함): 피아노 귀신 1회. "리코더를 힘껏 불어 피아노 소리를 덮었다! 리코더가 쪼개졌다."
- 부적(우리 반 사물함): 분신사바 귀신, 젖은 태민, 지은, 추격 중인 윤 선생님 중 1회. "부적이 타버렸다! ○○이(가) 잠시 사라졌다." (기도실 잠입 중 발각은 못 막음)
- 사용 순간 화면이 번쩍이고 2초 동안 잡히지 않으며, 귀신은 잠시 사라지거나 멀리 밀려나 도망칠 시간이 생긴다. 아이템은 보관함에서 사라진다.
- 인체 모형, 숨기 중 일찍 나오기는 아이템으로 막을 수 없다.

━━━━━━━━━━━━━━━━━━━━
9. 수첩, 쪽지, 세이브, 죽음
━━━━━━━━━━━━━━━━━━━━
- 수첩은 분신사바 직후부터 보유. 처음 Tab을 누르면 첫 장에 끼워진 쪽지(SujinHand)가 먼저 열린다:
  "이 수첩을 펼친 너에게. / 반짝이는 게시판 앞에서 수첩에 적으면 / 거기서부터 다시 시작할 수 있어. / 안 적으면? 그 교실부터 다시야. / 추신: 쫓기면 교실 사물함이나 교탁 밑. / 숫자 다 셀 때까지 절대 나오지 마. / - 2학년 3반 선배가"
- 수첩 화면: 왼쪽 "물건"과 "쪽지" 목록, 오른쪽 설명, 목표, 금고 비밀번호 진행(알아낸 숫자만 표시). 손전등은 [사용]으로 켜고 끄기.
- 쪽지는 자동 보관. 수첩에서 고르면 원래 쪽지 화면 그대로(글씨체, 번진 잉크 포함) 다시 열리고, 닫으면 수첩으로 돌아온다.
- 쪽지 목록과 글씨체:
  · 선배 쪽지(교실, SujinHand): "여기 수첩에 적어 둬. / 잡혀도 여기서 다시 시작할 수 있어. / 나도 그렇게 버텼어. / - 선배가"
  · 화장실 벽 낙서(MinjaeHand): "물 소리 나는 칸 앞으로 / 지나가지 마"

11. 소리
━━━━━━━━━━━━━━━━━━━━
11-1. 외부 소리 파일 (HTML과 같은 폴더)
- bgm_main.mp3: 평상시 배경음악(반복). scream_taemin.mp3: 태민 비명.
- 더블클릭으로 열어도 되도록 fetch 대신 new Audio()로 게임 시작 시 미리 불러둔다. .mp3가 없으면 같은 이름의 .m4a를 시도하고, 둘 다 안 되면 오류 없이 Web Audio 소리로 대체.
- 첫 키 입력 때 재생 시작(자동재생 제한). 볼륨은 audio.volume으로 설정값 적용.
- bgm_main은 평상시(복도·교실·교무실·현관·운동장, 추격·숨기·컷신이 아닐 때)만. 그 외 상황엔 약 1.5초에 걸쳐 작아졌다가 끝나면 다시 커진다. 귀신 등장 직전 정적과 기도실에서는 완전히 멈춘다. 평상시 BGM 파일이 재생되는 동안엔 코드로 만든 드론·형광등 소리는 끈다.
- 태민 비명: 파일이 playing 이벤트로 실제 재생되기 시작한 순간 "아아악—" 표시. 0.75초 안에 시작 못 하면 파일을 멈추고 Web Audio 비명으로 대체.

11-2. Web Audio로 만드는 소리
- 평상시(파일이 없을 때): 낮은 드론 + 멀리서 들리는 형광등 소리
- 구역별: 화장실(물방울), 과학실(유리 진열장 떨림), 음악실(「엘리제를 위하여」 멜로디를 직접 연주하되 음이 살짝 어긋나고 느리게 늘어지게, 가끔 크게 어긋난 음), 기도실(목탁 + 낮은 독경)
- 추격: 불협화 고음 + 점점 빨라지는 심장 박동 / 숨기: 배경음 거의 끄고 귀신 발소리만 크게
- 효과음: 발소리(귀신 발소리는 좌우 위치), 문, 사물함, 물 내림(좌우 위치), 펜 긁는 소리, 형광등, 지은 비명 "꺄아악—", 정문 끼익, 발차기, 지은 목소리, 리코더, 부적 타는 소리, 목탁, 금고 버튼, 아이템·저장 효과음, 점프스케어
- 프롤로그: 풀벌레와 바람 소리만

13. 기술 조건과 코드 정리
━━━━━━━━━━━━━━━━━━━━
- HTML 파일 하나(HTML + CSS + JavaScript, Canvas). 외부 이미지·라이브러리 없이 도트 그래픽은 코드로 직접 그린다(인물 4명 + 윤 선생님, 귀신들, 사물, 컷신 모두).
- 고정 60fps 업데이트. 대화·컷신 중에는 월드 정지.
- 맵, 대사, 귀신 등장 조건, 아이템, 쪽지, 이벤트(스텝 배열), 세이브 포인트, 목표 문구, 게임오버 문구, 퇴치 아이템 표, 건너뛰기 가능한 장면 목록은 데이터(CHAPTERS[1])로 분리해서 2장을 쉽게 추가할 수 있게.
- 기능별 구역(설정 / 데이터 / 렌더링 / 입력 / 귀신 AI / 이벤트 / UI / 사운드 / 메인 루프)으로 나누고 한국어 주석.

14. 이전 버전에서 실제로 났던 버그 (같은 실수 하지 않기)
━━━━━━━━━━━━━━━━━━━━
- 다른 맵으로 따라온 귀신에게 "등장 대기" 값이 남아 화면에 그려지지 않은 채 쫓아오던 버그.
- 잠긴 문에 비스듬히 부딪히면 바라보는 방향 반대로 밀려 벽 안에 갇히던 버그.

- 교실 한가운데에 캐비닛이 놓여 통로를 막던 문제.
